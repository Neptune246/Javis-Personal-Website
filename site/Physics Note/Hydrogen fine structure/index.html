    Ground state of hydrogen

    The ground state of hydrogen is \(n=1 \implies l=1\), \(j = |l-s|\) and \(j=l+s\), which there is only a value \(s = j =1/2\), so $$ \frac{\Delta E_1}{E_1^0} = \frac{\alpha^2}{n^2} \left( \frac{n}{j + 1/2} - \frac{3}{4} \right) = \alpha^2 \left( 1 - \frac{3}{4} \right) = \frac{\alpha^2}{4} $$

    Quantum number sets

    Very messy notation right? Here is the sum-up

    Initially, without perturbations, we are using \(n, l, m_l, m_s\) which corresponds to \(H^0, L^2, L_z, S_z\) where we ignore \(S^2\) because it has only one value which is \(s(s+1)\) (where \(s = 1/2\)) so it's not very useful.

    With perturbation, we are using \(n,l,j,m_j\) corresponding to \(H^0, L^2,J^2, J_z\) (ignoring \(S^2\)) since we are considering spin + orbital angular momentum. \(J^2\) has eigenvalues of \(j(j+1)\hbar^2\) and \(J_z\) has \(m_j\hbar\) ( where \(-j < m_j < j\) and \(|l-s| < j < l+s\))

    Balmer line energies

    Balmer line is from \(n = 3\) to \(n=2\) and by accounting the fine structure, we have

    Note that how \(n=3\) has five different labels with only three distinct \(j\) values (representing distinct energies). Based on Degenerate perturbation theory and hydrogen, the degeneracy is \(2n^2\) with perturbation, so we have 18 degeneracies with 3 different energies.

    For \(n=2\), there are 3 different labels, with 2 different \(j\) values and has 8 degeneracies.

    \(\implies\) there are 6 possible different transition energy. But we can only observe two strong spectral lines because it needs to follow the conservation of angular momentum:

    • Photon is a spin-1 particle, i.e. it removes or add a unit of angular momentum in our old system (atom before emiting or absorbing photon). So the system (atom) has to gain or lose a unit of angular momentum (\(\Delta j = 0, \pm1\))
    • For \(\Delta l = \pm 1\), it's because of electric dipole operator (dont know in details, left to be asked)
    • The transitions outside this requirement is forbidden

    This requirement removes some of the possibilities, leaving only with 7 labels with 5 energies. As the energy split gets smaller with increasing \(n\), they form 2 set of near degenerate lines \(n = 3 \rightarrow 2, 1/2\) (two lines) and \(n = 3 \rightarrow 2, 3/2\) (three lines). This is doublet.

    Lamb shifting

    Our calculation gave \(2p_{1/2}\) and \(2s_{1/2}\) as the same energy value but there is a very small difference due to lamb shift (an interaction between the electron and the vacuum fluctuations of the quantised electromagnetic fi eld) - degeneracy lifting

    Hyperfine splitting

    There is a even smaller energy shift of \(E^1_{n,\text{hyperfine}} \propto \alpha^4 m_e/m_p\) which arises because of proton's spin.

    The proton's spin gives a magnetic dipole of \(\boldsymbol{\mu}_p = g_p e/2 m_p \boldsymbol{S}_p\) and magnetic field of $$ \boldsymbol{B}_p = \frac{\mu_0}{4\pi r^3} \left[ 3(\boldsymbol{\mu}_p \cdot \hat{\boldsymbol{r}}) \hat{\boldsymbol{r}} - \boldsymbol{\mu}_p \right] + \frac{2\mu_0}{3} \boldsymbol{\mu}_p \delta(\boldsymbol{r}) $$ Recall from Degenerate perturbation theory and hydrogen that \(\underline{\boldsymbol{\mu}}_s = -e/m_e \boldsymbol{S}\), there is an additional contribution to the potential energy given by \(H' = \underline{\mu_e} \cdot B_p\)
