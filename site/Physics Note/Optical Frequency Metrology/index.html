    Optical Frequency Metrology

    Motivation

    The atomic clock has systematic error such as 2nd order Zeeman see Zeeman effect part 2, blackbody radiation and relativistic.

    The fractional uncertainty is given by $$ \sigma = \frac{\Delta \omega}{\omega_{12}} \sqrt{\frac{T_c}{N\tau}} $$

    where \(T_c\) is the time for single measurement, \(N\) is the number of atoms per measurement and \(\tau\) is the averaging time.

    To reduce \(\sigma\), we need to increase \(N\) and \(\tau\). However, it is hard to achieve both. Now both of these method use optical transitions as the frequency reference. (will be discussed in Trapped Ion and [[Optical Trap]])

    Question: How do we measure optical frequencies?

    Optical frequency comb

    We use pulsed femtosecond laser where the output looks like a ruler teeth of a comb and it can provide a relative frequency measurement but not an absolute measurement because we dont know the origin.

    [!note] The frequency of the \(n^{th}\) comb tooth is $\(\omega_n = \omega_{\text{CE}} + n\Delta\omega\)$ where \(\omega_{\text{CE}}\) is the carrier envelope offset frequency which can be found using octave spanning comb in PD2 parts in the setup diagram

    The setup is as such: we break this diagram into 3 parts: PD1, PD2 and PD3

    PD2

    Here is the part where we find \(\omega_{\text{CE}}\) using octave spanning comb. The input signal after the fibre is splitted into two parts, with one passing with the doubling crystal (nonlinear material which gives second harmonic generation) giving $\(\overline{\omega} =2\omega_n=2\omega_{\text{CE}}+2n\Delta\omega\)$ and another one passing right through the medium, maintaining the same \(\omega_{\text{CE}}\) and \(\Delta\omega\): $\(\omega_n' = \omega_{\text{CE}} +n'\Delta\omega\)$ The light then mixes and passes through the diffraction grating before reaching the photodiode 2 which measure the beat frequency (frequency between two teeth):

    [!note] $\(\omega_{\text{beat}} = \overline{\omega_n} - \omega_n' = 2\omega_n-\omega_n'=\omega_{\text{CE}}\)$ where we set \(n'=2n\) (?)

    Now we can measure optical frequency. We can use laser as oscillator in atomic clocks but the laser needs to be stable

    PD1

    • This is used to measure \(\Delta\omega\) and it is maintained constant by electronic feedback from the frequency counter to the laser.
    • 'Locking' laser to ultra stable reference cavity.

    PD3

    The laser with unknown frequency is introduced to the path to allow the mixing of light. A part of the light is used for experiments and another one is to measure the frequency of the laser.

    The laser frequency is then: $\(\omega_L = \omega_{\text{CE}} + n'' \Delta\omega +\omega_{\text{beat}}\)$ This can be derived from \(\omega_{\text{beat}}\)
